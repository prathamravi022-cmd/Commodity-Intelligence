Methodology

Assumptions, formulas and limitations behind every number in this dashboard.

Normalisation

Every contract is restated to one basis before any comparison:

INR per gram fine = price × (trading unit ÷ quoted unit) ÷ purity

GOLDM (10 g, 0.995), GOLDTEN (100 g, 0.995), GOLDGUINEA (10 g, 0.916) and GOLDPETAL (1 g, 0.995) therefore become directly comparable, and a spread is a real relative-value number rather than a unit mismatch.

Spread and z-score

  • Spread = leg A − leg B, both in INR per gram fine.
  • Carry adjustment removes the financing implied by the expiry gap; the rate lives in config/config.yaml and is currently 0.0, so the residual equals the raw spread.
  • Z-score = (residual − rolling mean) ÷ rolling standard deviation over a 60-session window.
  • Signal state machine: Neutral → Watch (inside the entry band) → Entered (|z| ≥ 2) → Exited (|z| ≤ 0.5). States are research labels, not orders.

Backtest design

  • Chronological split: 60% train, 40% out-of-sample — never shuffled, never re-fit on the test block.
  • Walk-forward re-estimation every 20 sessions.
  • Explicit per-leg, per-side costs: exchange fee, brokerage, statutory charges and slippage, in three scenarios (low / base / high).
  • Metrics are per pair; a pair below the minimum out-of-sample trade count is reported as underpowered rather than ranked.

Known limitations

  • Daily settlement prices only — not executable fill prices.
  • The carry rate is a documented input, not a sourced market rate.
  • Cost assumptions are illustrative until tied to a real fee schedule.
  • GOLDTEN's exchange history starts in 2025, so it contributes fewer sessions.
  • The bundled fixture expiries are fixed, so late sessions show settled contracts.
  • No theme toggle: Streamlit themes are fixed per deployment, and the dark workspace is the tested one.

Rebuilding this export

The Streamlit app is the interactive original and still runs from the repo root:

python -m streamlit run app/Home.py --server.port 8601

This static site is generated from the same committed artifacts and is what a static host serves:

python -X utf8 tools/build_static_site.py
